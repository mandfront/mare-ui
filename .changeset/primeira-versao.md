Primeira versão pública.

- `@mare-ui/tokens`: tokens no formato DTCG com temas claro e escuro e marcas, em variáveis CSS, tema do Tailwind CSS v4, valores com tipos e JSON.
- `@mare-ui/react`: Alert, AlertDialog, Avatar, Badge, Button, Card, Checkbox, Dialog, Switch, Tabs, TextField e VisuallyHidden, compatíveis com React Server Components.
